# Savant Chat Documentation

[Savant Chat](https://savant.chat) is an AI smart contract auditor. It finds
vulnerabilities in your code before attackers do — in 10–30 minutes for a
typical codebase, at a fraction of the cost of a manual audit.

## How it works

Savant Chat is not a static analyzer. Instead of pattern-matching known bug
shapes, a multi-agent stack runs thousands of specialized LLM calls over your
codebase:

- **200+ vulnerability classes** — each distilled from a real-world exploit in
  a 20,000-case vulnerability reference book.
- **Semantic analysis** — the agents trace value flows and model attacker
  incentives instead of matching syntax.
- **PoC validation** — a separate critic subagent builds a proof-of-concept
  for every finding before it reaches your dashboard. If the PoC fails, the
  finding is discarded.
- **Severity and confidence** — every finding ships with a severity rating and
  a confidence score, so you can triage fast.

## Quick start

1. **[Sign up](https://savant.chat/dashboard/login)** — you get **$75 free
   credit**, no credit card required.
2. **Upload your project** — a ZIP archive of your repository or a GitHub
   import.
3. **Run the audit** — severity-ranked, PoC-validated findings land in your
   dashboard in 10–30 minutes.

Follow the [Getting Started guide](/docs/getting-started) for a detailed
walkthrough.
